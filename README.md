# myblog

My blog based on Jekyll, used the theme <a href="https://github.com/Simpleyyt/jekyll-theme-next" target="_blank">jekyll-theme-next</a>.

## Why use Jekyll

<a href="https://docs.github.com/en/enterprise-server@2.21/github/working-with-github-pages/about-github-pages-and-jekyll" target="_blank">GitHub Pages</a> recommend it, and most important thing is that I am a newbie here.

## Objective for this blog

Only record the memo I met during working on my previous/current positions, in case someone hit the same issues or want to get some references. Hope it can help you and like it.

> **Please note that all articles are licensed under <a href="https://creativecommons.org/licenses/by-nc-nd/4.0/" target="_blank">CC BY-NC-ND 4.0</a>**

## Usage of this repository

You can fork my repository then edit `_config.yml` file to change the settings. Don't forget to remove all articles under the folder `_posts` and the relevant pictures under the folder `assets/images/`.
